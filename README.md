# 🤖 DevOps Troubleshooter AI Agent

An AI agent that automatically detects bugs in code and creates GitHub Issues with detailed bug reports.

## 🚀 What It Does
- Reads code files from GitHub automatically
- Detects bugs using Claude AI
- Creates GitHub Issues with bug details instantly

## 🛠️ Tools Used
- Relevance AI (Agent Builder)
- GitHub API (Code reading + Issue creation)
- Anthropic Claude AI (Bug detection)

## 📊 How It Works
1. User gives the agent a filename
2. Agent reads the code from GitHub
3. Claude AI analyzes the code for bugs
4. Agent automatically creates a GitHub Issue with the bug report
